# The app translates the backend's {"error": "..."} sentences, job and Library
# messages, catalogue genres and drive names through tr(), so they are keys in
# i18n/*.json although no tr() literal in src/ names them. tools/i18n-coverage.py
# treats the keys below as used; every other key must come from src/.
#
# One key per line, exactly as the backend or the catalogue sends it; a key with
# a leading or trailing space is written as a JSON string ("..."). A line
# "[backend]" or "[data]" sets the kind of the keys that follow; with --backend,
# the gate warns when a [backend] key is not a literal in the backend sources.
# Change a sentence here, in en.json and in the backend in the same commit; the
# sentences are listed in PORT-SPEC 1.3-1.5 and Appendix A and in the maps
# (map-downloads 12, map-library 6.7, map-system 5-6, map-catalog-art 3-9).
